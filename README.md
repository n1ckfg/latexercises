10 LaTeX self-teaching examples, all Overleaf compatible.

- 01_basic_document: minimal article structure
- 02_sections_crossref: sections, labels, cleveref cross-references
- 03_citations_bibliography: biblatex/biber with references.bib
- 04_footnotes_marginal: footnotes, marginal notes, critical apparatus
- 05_multilingual_critical: polyglossia, reledmac, parallel texts, stemma
- 06_figures_tables: subfigures, complex tables, booktabs, siunitx, longtable
- 07_math_algorithms: physics vectors, rendering equation, algorithms, code listings
- 08_twocolumn_siggraph: acmart sigconf format with teaser, CCS, anonymous review
- 09_tikz_graphics: 13 TikZ/PGFPlots diagrams (pipelines, NN, stemma, BRDF, plots)
- 10_complete_paper: dual-format template (DH single-col <-> Siggraph two-col)
